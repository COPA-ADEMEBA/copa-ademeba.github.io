# Copa ADEMEBA Yucatán 2026

Sitio informativo estático en HTML, CSS y JavaScript. No requiere compilación ni servidor de aplicaciones. Las imágenes se guardan en `assets/` y el contenido puede publicarse en GitHub Pages.

## Publicación

Este sitio se publica desde el repositorio público [`COPA-ADEMEBA/copa-ademeba.github.io`](https://github.com/COPA-ADEMEBA/copa-ademeba.github.io) con GitHub Pages. La URL institucional es [https://copa-ademeba.github.io](https://copa-ademeba.github.io).

GitHub Pages sirve los archivos estáticos de la raíz de `main`; no necesita compilación ni servidor de aplicaciones. La web es informativa: no vende, cobra ni procesa pagos o inscripciones. Para informes, dirige a WhatsApp.

Un dominio propio requiere registrarse por separado.

## Netlify como alternativa

El archivo `netlify.toml` permite publicar la misma carpeta en Netlify sin comando de compilación. Se puede conectar el repositorio de GitHub y asignar un subdominio `*.netlify.app` disponible.
